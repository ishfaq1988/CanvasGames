Canvas Games

Four HTML5 canvas games. Play against the computer, or play a friend on another device over a direct peer-to-peer connection. There's no game server, and each game is one file you can drop into any website.

Embedded demo

This is the same game inside an <iframe>, which is exactly how you'd put it on your own site.


  


  

    
How online play works

    

      
1 · Create a game
The host gets a short room code and a link to share.

      
2 · Find each other
Free public Nostr relays pass a one-time encrypted handshake. Prefer zero relays? Use the copy-paste codes option.

      
3 · Play direct
A WebRTC data channel links the two browsers. All game data goes device to device.
